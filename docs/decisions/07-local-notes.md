# 7. Each developer may keep notes of their own in a `CLAUDE.local.md`

- **Practice set aside:** a developer's own setup stays out of the project folder altogether, even git-ignored.
- **Why:** what that rule guards is not at stake: git ignores the file, so it is neither published nor cloned, and
  nothing versioned depends on it, so the project works the same for everyone.
- **Decided by:** the owner.
